1. Project Overview & Impact
Slide 2 / 12

The Challenge

Many farmers in Pakistan face crop losses due to common difficulties:

  • Late Diagnosis: Crop diseases are often not identified in time, leading to lower yields.
  • Lack of Experts: Rural areas lack quick access to trained agricultural advisors.
  • Weather Changes: Changing weather makes it hard to manage watering and planting schedules.
  • Market Gaps: Difficulty accessing transparent wholesale prices for fair crop sales.

The Solution

ArgoFarm provides an easy-to-use digital portal to support everyday farming:

  • Leaf Scanning: Identify crop health issues by uploading simple leaf photos.
  • Voice Assistance: Ask questions naturally in English or Urdu.
  • Crop Calendars: Get simple planning guides based on land size and budget.
  • Outbreak Radar: View general crop health trends and warnings by region.
2. Technology Stack
Slide 3 / 12

Backend & Database

  • Flask: Manages web requests and coordinates backend modules.
  • MySQL & SQLite: Relational data storage with automatic system fallbacks.
  • Security tools: Hashed passwords and secure session logins protect user accounts.
  • Local Classifier: Local model for soil-based crop recommendations.

Frontend & UI

  • Vanilla JS: Clean frontend logic for a fast user experience.
  • Mobile Design: Optimized layouts for field usage on mobile screens.
  • Interactive Maps: Displays general regional health summaries.
  • Simple Charts: Renders visual statistics for crop history logs.

Groq LLaMA

4. Diagnostics & Chat Advisor
Slide 5 / 12

AI Crop Disease Scan

  • Photo Upload: Farmers capture leaf photos to request health diagnostics.
  • Treatment Advisory: Delivers instant advice on organic cures, pesticide remedies, and preventions.
  • Dual Language: Instantly translates guides into clear English or Urdu.
  • Input Guard: Identifies and rejects blurry or non-crop photos, prompting users to try again.

CropMind AI Chat

  • Digital Advisor: Acts as a local agronomist, ignoring off-topic user messages.
  • Voice Assistance: Farmers record audio questions directly through the portal for ease of use.
  • Auto-Routing: Mentions of soil checks or disease scans automatically open the correct form.
  • Lightweight Context: Keeps track of recent conversation exchanges for continuity.
5. Soil Suggestions, Planner & Market
Slide 6 / 12

Soil Recommendations

Analyzes nitrogen, phosphorus, potassium, and climate inputs through a local model to recommend the best crop, followed by LLaMA-generated farming guides.

AI Crop Planner

Generates simple 4-month timelines based on budget, acreage, and water availability in English and Urdu to guide farmers from sowing to harvest.

Marketplace Analysis

Includes a notice board for wholesale listings. AI analyzes listing prices, checks mandi averages, and suggests pricing and negotiation ideas.

Outbreak Radar & Weather Warnings

Crop disease cases are displayed on a regional map. AI helps forecast spread risk levels (low, medium, high) in neighboring areas. Weather advisories are paired with basic action plans to help farmers protect their crops.

8. Admin Controls & Governance
Slide 9 / 12

User Management

  • Admin Panel: Restricted console allowing administrators to search and manage user registration records.
  • Auto-Bootstrap: Grants admin status to the first user or email starting with admin@ automatically.
  • Account Controls: Modify privileges, adjust roles, or delete inactive user records.

Custom Quota Settings

  • AI Limit Controls: Adjust daily AI request limits for individual accounts to manage server resource allocation.
  • AI Access Block: Setting limits to zero completely disables AI tools for selected accounts.
  • Lockout Safeguard: Prevents active admins from deleting their own accounts or demoting themselves.

Note: Safe admin validations ensure the running session administrator cannot accidentally trigger demotions on themselves, preventing system lockouts.

9. Platform Security Measures
Slide 10 / 12

Account Safeguards

  • Secure Hashing: Bcrypt password hashing prevents storing user passwords in plaintext.
  • Token Sessions: Signed Web Tokens handle secure authentication across browser sessions.
  • Session Expiry: Automatic logout clears cached tokens if session expires.

API and Database Integrity

  • Query Parameterization: Eliminates SQL injection threats across database connections.
  • Email Sanitization: Normalizes inputs to prevent duplicate registrations.
  • Environment Isolation: Sensitive credentials and API keys are stored in secure environment files.
10. Deployment & Infrastructure
Slide 11 / 12

Containerized Stack

Docker Compose maps and deploys four isolated services:

  • Database service: MySQL database container with health checks and volumes.
  • Backend application: Flask server container running core routes.
  • Proxy router: Nginx gateway managing SSL and request directions.

Static Web Hosting

  • Frontend CDN: Hosted on a global network (Netlify) for fast load times.
  • Proxy Rules: Redirects backend queries smoothly to bypass browser security issues.
