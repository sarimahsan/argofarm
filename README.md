# 🌾 ArgoFarm — AI-Powered Crop Diagnostics & Advisory Platform

Intelligent crop disease detection, weather advisory, and farmer decision-support system for Pakistan — powered by Google Gemini 2.5 Flash Vision, Groq LLaMA, and community-driven insights.

---

## 📋 Tech Stack

| Component | Technology |
|-----------|-----------|
| **Backend** | Flask (Python 3.9+) + MySQL / SQLite |
| **Frontend** | Vanilla JavaScript + Vite |
| **AI Vision** | Google Gemini 2.5 Flash (crop disease diagnosis) |
| **AI Chat** | Groq LLaMA 3 (CropMind advisor) |
| **Voice Input** | Groq Whisper (audio transcription) |
| **Weather** | Open-Meteo API + Gemini advisory |
| **Map** | Leaflet.js (disease outbreak radar) |
| **Charts** | Chart.js (health analytics) |
| **Deployment** | Netlify (frontend) + VPS / Docker (backend) |

## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- Node.js 16+
- MySQL 8.0+ *(optional — SQLite auto-fallback)*
- Git

### 1️⃣ Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate
# Activate (Mac/Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create .env file (see Environment Variables section below)

# Initialize database (creates all tables automatically)
python init_db.py
# ✅ If MySQL is configured: uses MySQL
# ✅ If MySQL unavailable: auto-creates SQLite (local_db.sqlite)

# Start server
python app.py
# Runs on http://localhost:5000
```

### 2️⃣ Frontend Setup

```bash
cd frontend

# Install dependencies
npm install

# Start dev server
npm run dev
# Runs on http://localhost:5173

# Build for production
npm run build
```

## 🚢 Deployment

### Frontend → Netlify

1. Build the frontend:
   ```bash
   cd frontend && npm run build
   ```
2. Deploy the `dist/` folder to Netlify (drag-and-drop or via CLI).
3. API proxy is handled automatically via `frontend/public/_redirects`:
   ```
   /api/*      http://<YOUR_VPS_IP>:3000/api/:splat      200!
   /static/*   http://<YOUR_VPS_IP>:3000/static/:splat   200!
   /*          /index.html                                200
   ```

### Backend → VPS / Docker

**Option A: Direct**
```bash
cd backend
python app.py
# Runs on port 3000 (production) or 5000 (development)
```

**Option B: Docker Compose**
```bash
docker-compose up -d
# Starts: MySQL + Flask backend + Nginx reverse proxy
```

## 🔐 Environment Variables

Create `.env` in `backend/`:

```env
# Database (MySQL — leave blank for SQLite fallback)
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=agrofarm

# JWT
JWT_SECRET=your_super_secret_key_change_this
JWT_EXPIRY_DAYS=7

# Google Gemini AI (Vision + Text)
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash

# Groq AI (Chat + Whisper)
GROQ_API_KEY=your_groq_api_key

# Flask
FLASK_ENV=development
FLASK_DEBUG=1
```

## 🚨 Common Issues

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError: No module named 'flask'` | Run `pip install -r requirements.txt` |
| `Error connecting to MySQL` | Check DB credentials in `.env`, or let SQLite auto-fallback |
| `GEMINI_API_KEY not set` | Add your Google Gemini API key to `.env` |
| `GROQ_API_KEY not set` | Add your Groq API key to `.env` |
| `Vite dev server fails` | Clear `node_modules` and run `npm install` again |
| `Mixed Content on Netlify` | Ensure `_redirects` file proxies `/api/*` to your backend |
| `CORS errors` | Backend has `CORS(origins="*")` — check your proxy config |

## 📝 Architecture Notes

1. **Backend API** responses use standard JSON: `{status, data, message}`
2. **Frontend state** is managed globally in `src/state.js`
3. **Auth token** stored in `localStorage` with key `authToken`
4. **AI Models** use a fallback chain: Gemini 2.5 Flash → Gemini 3.5 Flash
5. **Groq** handles chat completions (LLaMA) and audio transcription (Whisper)
6. **Weather** uses Open-Meteo (free, no API key) with Gemini-generated crop advisories
7. **Outbreak Radar** auto-updates with Leaflet.js when the dashboard loads
8. **ML pipeline** loads pre-trained TensorFlow + scikit-learn models at startup
9. **Rate limiting** is applied on wholesale AI analysis (10s cooldown per user)
10. **Netlify proxy** via `_redirects` avoids mixed-content issues in production
